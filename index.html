JEWEL

Tienda Online de Joyería

Plataforma e-commerce completa · 2025

Descripción

El Proyecto

Desarrollo completo de una plataforma e-commerce de joyería de lujo, desde cero hasta producción. Incluye la vitrina pública, sistema de autenticación, carrito de compras, pasarela de pagos, cuentas de cliente, panel administrativo y backend robusto con base de datos en la nube.

Alcance

Módulos del Desarrollo

01

Vitrina Pública

La cara visible de la tienda: todas las páginas que el cliente final navega.

Página principalHero banner, colecciones destacadas, bestsellers, historia de marca, newsletter
Catálogo de productosGrilla con filtros por categoría, material, precio y colección
Detalle de productoGalería de imágenes, selector de talla, productos relacionados
ColeccionesPágina de colecciones + detalle individual con productos asociados
Carrito de comprasDrawer lateral + página completa, persistencia, cálculo de impuestos
Checkout multi-pasoDatos de envío → Pago → Revisión → Confirmación
Páginas informativasAbout (historia de marca), Contacto
Diseño responsiveAdaptado a móvil, tablet y desktop
AnimacionesTransiciones suaves, parallax, micro-interacciones
02

Autenticación y Cuentas

Sistema completo de registro y gestión de cuenta para los compradores.

Registro e inicio de sesiónEmail/contraseña con validación segura
Recuperación de contraseñaFlujo completo con envío de email y confirmación
Dashboard de cuentaVista general de actividad del cliente
Historial de órdenesLista de compras con estado y detalle de cada orden
Direcciones de envíoCRUD de direcciones, dirección principal seleccionable
Lista de deseosGuardar productos favoritos, sincronizado con backend
Configuración de perfilEditar nombre, email, cambiar contraseña
03

Pasarela de Pagos

Integración profesional para recibir pagos de forma segura.

Stripe (internacional)Pagos con tarjeta, configuración live, webhooks certificados
Nubiz (mercado local)Pasarela alternativa para mercado peruano/latam
Confirmación automáticaAl aprobarse el pago se crea la orden y se notifica al cliente
Manejo de reembolsosProceso de devolución desde el panel admin
Registro de transaccionesLog de pagos exitosos y fallidos con detalle
04

Panel Administrativo

Dashboard privado donde el administrador gestiona toda la tienda sin tocar código.

Dashboard principalVentas del día/mes, órdenes pendientes, stock bajo, gráficos
Gestión de productosCRUD completo. Subir imágenes, asignar colecciones, precios, stock
Gestión de coleccionesCRUD con imagen hero y descripción
Gestión de categoríasCRUD de categorías de productos
Gestión de órdenesVer todas, cambiar estado, filtrar por fecha/estado
Gestión de clientesLista de registrados, historial de compras, detalle individual
Control de inventarioAlertas de stock bajo, ajuste manual, descuento automático al vender
Subida de imágenesUpload con optimización automática (formato, tamaño)
05

Backend y Base de Datos

Infraestructura sólida: Supabase + Next.js API.

Base de datos (Supabase)PostgreSQL administrado en la nube, migraciones, backups automáticos
API (Next.js)Rutas API RESTful para productos, órdenes, usuarios, carrito, imágenes
Autenticación (Supabase Auth)Registro, login, OAuth, recuperación, sesiones seguras
Almacenamiento (Supabase Storage)Buckets para imágenes con CDN integrado
Row Level SecurityPolíticas de seguridad a nivel de base de datos
Validación de datosEsquemas estrictos con Zod en todas las entradas
Rate limitingProtección contra abuso en endpoints públicos
06

Funcionalidades Adicionales

Value-add features para una experiencia profesional completa.

Buscador de productosBúsqueda por nombre, material, colección con resultados instantáneos
Reseñas de productosSistema de rating + comentarios verificados por compra
Notificaciones por emailConfirmación de orden, actualización de estado, bienvenida
Optimización SEOMeta tags, Open Graph, sitemap XML, structured data para Google Shopping
Optimización de rendimientoLazy loading, code splitting, imágenes WebP, Core Web Vitals
07

Calidad, Testing y Despliegue

Garantía de calidad y puesta en producción.

Pruebas automatizadasTests unitarios y E2E de flujos críticos (compra, registro, admin)
Configuración de producciónVariables de entorno seguras, headers de seguridad, SSL
Despliegue en VercelPipeline de deploy continuo, dominio personalizado, HTTPS
DocumentaciónGuía de uso del panel admin + manual de operación básica
